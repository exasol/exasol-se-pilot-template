# Pilot Live Runbook

This runbook records live operational state for a generated Exasol SE pilot.
It starts as a neutral placeholder and must be populated after the first
environment deployment.

## 1 Service Inventory

Record deployed ServiceURIs, ownership, authentication boundary, and the
runtime account, region, and Availability Zone.

## 2 Operating Window

Record normal start/stop schedules, manual override policy, and notification
recipients.

## 3 Health Checks

Record private and public smoke commands for Exasol Personal, MCP, Streamlit,
Grafana, chatbot, Operator Dashboard, Cognito, SES/SNS, Lambda, and S3.

## 4 Daily Operations

Keep the daily operations cheatsheet here after deployment. Link every command
to the owning deployment or operations runbook when the command mutates cloud
state.
